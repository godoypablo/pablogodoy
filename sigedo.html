SIGEDO

Sistema Integrado de Gestión Electrónica de Documentos

¿Qué es SIGEDO?

SIGEDO es un sistema web profesional especializado en la gestión de documentos de auditoría para el Tribunal de Cuentas de Entre Ríos (TCER), una institución argentina que audita y controla las cuentas del gobierno provincial.

El sistema permite recibir documentos financieros (rendiciones, subsidios, multas), procesarlos a través de múltiples etapas de revisión y auditoría, y finalmente certificarlos con firma digital, manteniendo un registro imutable de cada acción.

Flujo Principal

↓

✍️ Se firma digitalmente

↓

✅ Se genera PDF oficial certificado

Tipos de Documentos que Gestiona

📊 Rendiciones

Cuentas anuales de organismos, subsidios y gastos públicos

📁 Expedientes

Carpetas de auditoría con documentación completa

⚠️ Multas

Penalizaciones por incumplimiento

❌ Omisiones

Avisos automáticos de no entrega de cuentas

Tecnología

Lenguaje: Java 11 (compilado, rápido, seguro)

Framework Web: Wicket (componentes reutilizables)

ORM: Hibernate (traduce objetos Java a BD)

Base de Datos: PostgreSQL (profesional, confiable)

APIs REST: Apache CXF (integración con otros sistemas)

Reportes: JasperReports (PDF bonitos)

Inyección de Dependencias: Spring (organiza componentes)

Firma Digital: Integración con certificados electrónicos

Build: Maven (gestión de dependencias)

Logging: SLF4J + Logback (trazabilidad)

Seguridad: Control de acceso basado en roles (RBAC)

Auditoría: Registro imutable de todas las acciones
